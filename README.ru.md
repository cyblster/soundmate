# soundmate

[English](README.md) | **Русский**

soundmate — музыкальный бот для Discord, который разворачивается на собственном сервере. Бот
воспроизводит аудио с YouTube и SoundCloud в голосовых каналах. Управление осуществляется через
постоянный плеер в выделенном текстовом канале, а также с помощью слэш-команд.

## Возможности

- Постоянные сообщения плеера и очереди, обновляемые на месте
- Поиск по YouTube или SoundCloud с выбором из пяти лучших результатов, поддержка прямых ссылок
  на треки и плейлисты
- Воспроизведение прямых трансляций YouTube
- История воспроизведения последних 20 треков для каждого сервера
- Интерфейс на английском и русском языках, настраиваемый для каждого сервера

## Требования

- Сервер с установленными [Docker](https://docs.docker.com/get-docker/) и Docker Compose
- Приложение Discord с ботом

## Установка

1. Создайте приложение в [Discord Developer Portal](https://discord.com/developers/applications),
   добавьте бота и скопируйте его токен. Привилегированные интенты не требуются.
2. Пригласите бота на сервер Discord, заменив `<APP_ID>` на ID вашего приложения:

   ```
   https://discord.com/oauth2/authorize?client_id=<APP_ID>&scope=bot+applications.commands&permissions=271666192
   ```

3. Создайте файл конфигурации и укажите в нём `BOT_TOKEN`:

   ```bash
   cp .env.sample .env
   ```

4. Соберите и запустите сервисы:

   ```bash
   docker compose up -d --build
   ```

5. В Discord откройте текстовый канал, предназначенный для музыки, и выполните `/setup`. Для
   русского интерфейса выполните `/setup language:ru`.

## Использование

| Управление                    | Доступно                              | Действие                                                  |
|-------------------------------|---------------------------------------|-----------------------------------------------------------|
| `/setup`                      | Администраторам                       | Назначает текущий канал музыкальным. Параметр `language`: `en` (по умолчанию) или `ru` |
| **Добавить**, `/add`          | Участникам в голосовом канале         | Открывает форму для поискового запроса или ссылки и выбора источника поиска. `/add query:<текст или ссылка>` выполняет поиск сразу, `source:SoundCloud` ищет на SoundCloud вместо YouTube |
| **Пропустить**, `/skip`       | Участникам в голосовом канале бота    | Переходит к следующему треку                              |
| **Отключить**, `/disconnect`  | Участникам в голосовом канале бота    | Останавливает воспроизведение, очищает очередь и покидает голосовой канал |
| **Недавнее**, `/history`      | Всем участникам                       | Отображает последние 20 треков, воспроизведённых на сервере |

Слэш-команды доступны во всех текстовых каналах сервера после выполнения `/setup`. Ответы на них
видны только участнику, который вызвал команду. Повторное выполнение `/setup` в другом канале
переносит плеер в этот канал.

## Настройка

Бот считывает конфигурацию из файла `.env`.

| Переменная   | Обязательна | По умолчанию | Описание                          |
|--------------|:-----------:|--------------|-----------------------------------|
| `BOT_TOKEN`  | Да          |              | Токен Discord-бота                |
| `LL_OPTIONS` | Нет         | `-Xmx512M`   | Параметры JVM для Lavalink        |
| `DEBUG`      | Нет         | `false`      | Включает отладочное логирование   |

PostgreSQL и Lavalink доступны только во внутренней сети Docker. Порты на хосте не публикуются.

## Устранение неполадок

| Проблема                                  | Решение                                                          |
|-------------------------------------------|------------------------------------------------------------------|
| Треки пропускаются или не воспроизводятся | YouTube часто вносит изменения. Обновите версию плагина YouTube в `lavalink/application.yaml` и выполните `docker compose restart soundmate-ll` |
| Бот не отвечает                           | Просмотрите логи командой `docker compose logs -f soundmate-bot` |
